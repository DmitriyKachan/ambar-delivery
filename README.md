# 🍽️ Кафе-ресторан «Амбар» (Запоріжжя) — Оновлена платформа доставки

Сучасний інтерактивний веб-сайт ресторану «Амбар» (м. Запоріжжя, вул. Олександрівська, 88) із повнофункціональною системою онлайн-замовлення, особистим кабінетом клієнта, інтерактивним бронюванням столів та панеллю керування адміністратора.

---

## 🔒 Безпека та приватність

> **Важливо**: Цей репозиторій є **приватним** (`Private`). Доступ до коду, структури бази та алгоритмів має виключно власник облікового запису.

- **Захист від витоку даних**: Клієнтські дані (номери телефонів, адреси, замовлення) шифруються та зберігаються ізольовано, без доступу сторонніх скриптів.
- **Безпечна адмін-панель**: Вхід в панель керування замовленнями захищено через сесійний контроль.

---

## 🚀 Як запускати та редагувати з інших пристроїв

Проект побудовано на чистому стеку (HTML5, Tailwind CSS, Vanilla JS) — **не потребує складної збірки чи встановлення важких пакетів**:

1. **Клонування на іншому пристрої**:
   ```bash
   git clone https://github.com/DmitriyKachan/ambar-delivery.git
   cd ambar-delivery
   ```

2. **Запуск у браузері**:
   - **Варіант А**: Просто відкрийте файл `index.html` або `ambar_redesign/index.html` у будь-якому браузері (Chrome, Safari, Edge, Firefox).
   - **Варіант Б (через Live Server / локальний сервер)**:
     ```bash
     # Через Python (вже вбудований у macOS та Linux):
     python3 -m http.server 8080
     # Потім відкрийте в браузері: http://localhost:8080
     ```
   - **Варіант В (VS Code / Cursor / iPad)**:
     Встановіть розширення **Live Server** і натисніть «Go Live».
